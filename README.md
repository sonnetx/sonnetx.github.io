# sonnetx.github.io

The About page text lives in `about.md`. Edit it as plain markdown and GitHub Pages builds it into `about.html` using `_layouts/about.html`. It has a tab in the sidebar, and the name at the top of the sidebar links there too. A hover note on a word in the text comes from `_includes/note.html`, as on brunch.

Books live in `_data/reading.yml`, split into `current`, `to_read`, `finished` and `shelved` (abandoned). Each book has an `added` date for when it went into its list. The Reading page (`reading.html`) shows each list as a shelf of covers that scrolls sideways once it outgrows the page, with the title, author and date under each cover. The popup over the word reading on About shows the current books, or the three most recent finished ones when nothing is current.

Covers live in `photos/books/`, named after the slugified title (`photos/books/the-painted-veil.jpg` for The Painted Veil), so the YAML needs no cover field. After adding a book, run `python3 scripts/fetch_covers.py` to download any missing covers from Open Library. A book without a cover file shows a plain title card. If the script picks a poor edition, find a better one on openlibrary.org and run `python3 scripts/fetch_covers.py --cover "<title>" <cover id>`.

There is no Writing page for now, and the old `writing.html` and `blog.html` URLs redirect to the homepage. The old Compute page is gone too, and `compute/` redirects to Projects. Community (`community.html`) has no tab, and About links to it.

Projects (`projects.html`) opens with Highlighted projects, a two-column grid of the projects to feature, followed by Other projects, a grid of smaller tiles whose pictures stay muted until hovered. Every card has a 16:10 image from `photos/projects/` (1000x625 JPEGs). The torch_measure, condor-rs and AI for Design images are simple illustrations, since those repos have no figures of their own. A comment above the sections shows how to add a project. The `preference-first/` folder holds the Preference-First Medical AI demo, copied from `demo/index.html` in that project's repo with four changes so it looks like the rest of the site. The copy gains the empty front matter, the sidebar include, `data-theme="light"` on `<html>`, and a link to `preference-first/site.css` after its own `<style>` block. It also swaps the demo's Google Fonts for the site's stylesheets and replaces its small header with a page title. The JavaScript is untouched. To update the demo, copy the new `demo/index.html` over this one and redo those changes. `site.css` holds every style override and does not need to change.

Every page shares the sidebar in `_includes/sidebar.html`, styled by `sidebar.css`. Each page pulls it in with `{% include sidebar.html active="research" %}`, where `active` names the highlighted tab. The homepage bio sits in a `capture` block at the top of `index.html` and only shows on the homepage. Pages need the empty `---` front matter at the top so GitHub Pages runs the include.
