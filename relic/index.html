RELIC

A coding agent can write a compiler. This asks whether it wrote the one in the manual.

September 2026 · CodeResults

C is the language a coding agent has seen most. A perfect C compiler tells you the model can produce a C compiler. It cannot tell you whether the model read the specification or remembered one. RELIC generates the language instead, so the manual is the only place the rules exist.

The base is B, the language C came from. Eighteen of its design decisions are knobs: which character quotes a string, what the plus sign means, whether else binds to the nearest if, whether a pointer steps by a word or a byte. A seeded generator permutes some of them. Every variant is as hard as B for someone who has never seen either, and wrong for anyone relying on habit. The same seed writes the manual and configures the interpreter that grades the compiler, so the two cannot drift apart.

The agent receives the manual, a small stack machine, and twenty-two example programs. It gets four rounds of feedback on those examples. The score is one hundred programs it has never seen.

The same run is not a measurement

The first sweep looked finished. One model scored perfectly on four languages that do not exist. Each cell had been run once.

Three runs of the same model, on the same manual, with the same prompt, had a median spread of fifty points. The worst was the whole scale. Gemini 3.7 Flash, on the variant whose operators no longer mean what training says they mean, scored 0% on one run and 100% on another. A leaderboard of single agent runs at this size is a coin flip with a model name on it.

What survives the repeats is narrower. For Gemini 3.1 Pro, the base language still overlaps the variants that only change spelling or grammar. The two variants that change what the operators mean sit entirely below it, between 0% and 25% where the base language ran from 29% to 100%. Flash scored 100% on every lexical and syntactic run, with no spread at all. A different comment delimiter costs it nothing. Meaning is where the runs come apart.

They read the manual

The examples include the output a correct compiler should produce, so a model could induce the language from the tests and never open the prose. An ablation withholds every expected output. Feedback names the failing program and what the compiler printed, never what was right. The manual is the only source of the semantics.

Five of those six runs still passed hidden programs, and three passed all of them, on variants where a compiler that assumes B scores 8% or nothing. The manual was enough.

A smaller model did the thing the benchmark was built to catch. Qwen3.5 9B, on the most mutated variant, compiled + as addition, − as subtraction, and / as division. The manual assigns those three spellings division, addition, and subtraction. Its reasoning trace never mentions the operator table. It read a language that cannot exist in any training set and wrote a compiler for the one it already knew.

A test suite certifies the rules it decides

The hidden suite has a hole, and two perfect scores fall through it. Of the hundred programs, none are decided by the string terminator, the unit of pointer arithmetic, the order of argument evaluation, or one of the truth rules. The semantic variant changes two things, the arithmetic table and the pointer unit, and every program it decides is decided by the arithmetic. A compiler that copies the table and ignores the pointer unit scores 100%.

Two of Flash's perfect compilers do that. A separate rubric, one small program per rule, fails them on both pointer items. The suite cannot see the miss. Under byte addressing a one-word step is misaligned and traps, so no program that has to stay valid in every variant can contain that step, and the generator had no way to write a step in the variant's own unit.

The distance between the tests an agent can see and the tests it cannot is the same failure, measured rather than read out of a diff. Of twenty-six runs that passed every program they were shown, twenty-four also passed every hidden program. One passed 55%. One passed none. On the semantic variant, Pro's compilers pass 88% of the programs in front of them and 12% of the programs that are not, in all four runs.

The repository is the benchmark, the interpreter, and every compiler these numbers come from. They can be regraded from disk. The suite still does not decide every rule. That limit is written down next to the scores, which is as finished as this measurement gets.
